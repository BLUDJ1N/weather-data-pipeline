# Витрина погодных данных

## Цель проекта

Построить витрину погодных данных: подготовить почасовые показатели и дневную сводку по Воронежу, Москве и Санкт-Петербургу.

## Стек

Python, SQL, Apache Airflow, PostgreSQL, Docker, Git.

## Что сделано

- Разработал Python-скрипт для получения почасовой температуры, осадков и скорости ветра из API Open-Meteo.
- Преобразовал ответ API в записи с названием города и временем с часовым поясом. Добавил проверки пропусков, отрицательных осадков и скорости ветра, а также совпадения длины списков.
- Настроил загрузку в PostgreSQL с обновлением существующих строк по ключу «город + время» при повторном запуске.
- Подготовил SQL-представление с дневными показателями: средней, минимальной и максимальной температурой, суммой осадков и максимальной скоростью ветра.
- Собрал DAG из одной задачи в Airflow: ежедневный запуск пайплайна в 09:00 по Москве и две повторные попытки при сбоях.

## Результат

Реализовал единый пайплайн от ответа API до дневной витрины в PostgreSQL. При проверке за 1–3 октября 2026 года обработано 216 почасовых записей и получено 9 строк дневной сводки. Повторная загрузка не создаёт дубли по ключу «город + время».
